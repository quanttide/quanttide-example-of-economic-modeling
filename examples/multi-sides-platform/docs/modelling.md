# 建模笔记

将 `pl`（入驻费）设为外生，是一种非常经典的**分解复杂问题、逐步深入**的建模策略。这通常基于以下几点考虑：

---

### 1. 分解复杂问题：先从“参数”入手，再看“最优决策”

完整的三边市场模型需要平台同时决定 `pu`、`pf`、`pl` 三个价格。这是一个三维优化问题，产生的均衡条件复杂，闭式解难以获得，多重均衡的可能性也更高。

将 `pl` 外生，相当于在问：
> “**假如**平台向每个商家收取 `pl` 这么多入驻费，那么它会把用户价格 `pu` 定在什么水平？在什么条件下会出现免费出行？”

这等价于先做一个**比较静态分析**：研究 `pl` 这个关键变量如何影响均衡结果。它为后续将 `pl` 内生化铺平道路——你很快会发现 `pl` 对利润的影响是非单调的，存在一个最优的 `pl*`。外生分析为内生优化提供了直觉和验证基准。

从 `foc_pu_eq = 0` 解出的 `pu*(pl) = (A + β·B + α·c - (β + γ·α)·pl) / (2α)` 本质上是一条**反应函数**。当 `pl` 内生化时，第二条 FOC（`foc_pl_cond` 的等式形式）将与这条反应函数相交，共同决定均衡的 `(pu*, pl*)`。当前外生分析正是在为这个二维系统搭建脚手架。

---

### 2. 政策实验与反事实分析

很多有价值的问题本身就是“政策实验”式的，需要某些变量固定不变。

-   **短期 vs 长期**：在短期内，商家的入驻费可能是由市场竞争、合同约定或平台战略决定的“既定政策”。模型可以分析在这种既定政策下，用户端的价格和补贴会如何调整。
-   **最坏情况分析**：如果 `pl` 因竞争压力被压得很低，平台还能不能实现免费出行？这对应着寻找使 `pu ≤ 0` 成立的 `pl` 临界值。
-   **场景规划**：业务方可以直接问：“如果我们的销售团队能把入驻费谈到 5000 元，我们能补贴用户多少钱？出行量会到多少？”——外生 `pl` 让模型能直接回答这类问题。
-   **拐点扫描**：固定其他参数、遍历 `pl` 取值，找到 `pu` 从正转负的临界点。Python 端 `scan_parameter_range("pl", [...])` 直接实现这一分析——输出表格显示每个 `pl` 下的均衡 `pu` 值，便于快速定位免费出行阈值。

---

### 3. 模拟“商家端不完美竞争”的简化处理

在现实中，平台对商家的收费能力受到**商家外部选择**的约束。

-   如果目的地周边已经有成熟的商业综合体或成熟的引流渠道，平台就不能任意定高价，`pl` 实际上被外部市场环境“给定”了。
-   外生 `pl` 对应两种可能的经济解释：
    1. **短期合约锁定**：平台与商家的入驻合同已签，`pl` 在合约期内固定，平台只能在用户端灵活调整
    2. **外部竞争约束**：商家有替代引流渠道（如自有门店客流），平台必须将 `pl` 定在不超过外部选项的水平

两种解释都不需要假设"平台是价格接受者"，只需说明 `pl` 在当前分析中固定。

---

### 4. 技术实现上的“软着陆”

您之前用 Pyomo + PATH 求解 MCP 模型，并计划用 Lean 形式化。需要区分"外生"是指**分析策略**而非模型结构：

-   **MCP 层面**：`pl` 仍是内生变量（`ModelVars.pl` + `h_foc_pl`），保证了未来扩展为联合优化时模型结构不变。这里的"外生"是分析策略——推导 `pu*(pl)` 时把 `pl` 视为参数，聚焦于"给定 `pl` 时的最优 `pu`"
-   **Lean 形式化**：定理的假设条件中将 `pl` 作为自由变量传入（如 `CriticalCondition(p, pl)`），减少存在性证明同时保留 `Equilibrium.h_foc_pl` 的结构完整性
-   **迭代路径**：先用外生分析跑通"建模-求解-验证-定理证明"的闭环，确认一切无误后再在分析层面放开 `pl` 为自由决策变量——届时只需添加第二条 FOC 条件，无需修改模型结构。这是风险最低的路径。

---

### 💎 总结

把 `pl` 设为外生，并不是放弃对现实的拟合，而是把研究问题精确地界定为：
> “在平台可以自由决定对用户的收费（和补贴），但向商家的收费能力受外部环境或短期合约限制的条件下，模型的均衡是什么？”

这是一个在理论深度和可解性之间取得很好平衡的起点。您的新模型已经证明，在这种设定下，存在一个清晰的、由商家入驻费驱动的免费出行临界条件，这本身就是理论洞见。

下一步，如果要把 `pl` 内生化，最自然的扩展是让平台**联合优化 `pu` 和 `pl`**（或许先保持 `pf = 0`）。这会得到一个二维的 FOC 系统，可以用来分析：平台的最优 `pl*` 由哪些参数决定？它和市场饱和、免费出行之间的完整关系是什么？届时，您现在推导的所有外生 `pl` 下的结论，都将成为理解更复杂模型的阶梯。
