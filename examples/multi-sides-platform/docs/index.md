# 多边平台经济模型

## 一句话讲清这个项目在做什么

一个**结果交付型城际出行平台**的 MCP 均衡模型——平台向商家收入驻费，用这笔钱补贴用户出行。模型回答的核心问题是：**在给定市场参数下，这个生意是否值得做？**

---

## 三句话讲清模型逻辑

```
         你（用户）          商家
            ↘              ↗
        付票价（可负）    交入驻费
            ↓           ↑
            ﹊﹊ 平 台 ﹊﹊
```

1. **用户**想要便宜甚至免费的出行（\(Q = A - \alpha p_u + \beta N\)）
2. **商家**想要更多客流（\(N = B + \gamma Q - \delta_f p_f - \delta_l p_l\)）
3. **平台**当中间人——向商家收入驻费，用这笔钱补贴用户（\(\pi = \underbrace{(p_u - c)Q}_{\text{客运收入}} + \underbrace{p_f N Q}_{\text{流量费}} + \underbrace{p_l N}_{\text{入驻费}}\)）

---

## 模型回答了什么问题？

### 1. 这个模式能不能赚钱？

盈利的充要条件是一个简洁的不等式：

\[
A + \beta B > \alpha c
\]

三个要素决定一切：

| 要素 | 含义 | 如何提升 |
|------|------|----------|
| \(A + \beta B\) | 净需求 = 基础出行 + 商家网络效应拉动 | 聚焦高吸引力商家（提升 \(\beta\)），扩大基础客群（提升 \(A\)） |
| \(\alpha\) | 用户价格敏感度 | 通过品牌或补贴培养习惯，降低敏感度 |
| \(c\) | 出行技术成本 | 技术降本（拼车、路线优化） |

这条不等式不成立时，**无论怎么优化定价，最优利润都是零**。应该在商业模式层面找问题，不是定价策略。

成立时，最优利润为：

\[
\pi^* = \frac{(A + \beta B - \alpha c)^2}{4\alpha(1 - \beta\gamma)}
\]

### 2. 入驻费定多高合适？

入驻费 \(p_l\) 是把双刃剑：

- **提高 \(p_l\)**：直接增加收入，但抑制商家入驻（通过 \(\delta_l\)），削弱网络效应
- **降低 \(p_l\)**：吸引更多商家，放大 Q-N 正反馈，但直接收入减少

存在一个最优 \(p_l^*\) 使利润最大化（二阶条件保证为最大值）。超过此值后提高入驻费反而降低总利润。

### 3. 市场饱和后怎么办？

当 \(Q\) 触及市场容量上限 \(M\) 时：

\[
\frac{\partial Q}{\partial p_u} = 0
\]

价格弹性消失，补贴对规模增长毫无作用，只会侵蚀利润。饱和区的利润完全依赖商家端收入：

\[
\pi = p_f \cdot N \cdot M + p_l \cdot N
\]

**必须将定价策略从"用户补贴"切换为"商家价值深挖"**。

### 4. 为什么可以一边补贴一边赚钱？

核心在网络效应乘数：

\[
\text{补贴乘数} = \frac{\alpha}{1 - \beta\gamma}
\]

每补贴 1 元，直接吸引 \(\alpha\) 个用户。这 \(\alpha\) 个用户通过 \(\gamma\) 吸引商家，商家再通过 \(\beta\) 吸引更多用户……循环放大。总效果是直接效果的 \(1/(1 - \beta\gamma)\) 倍。

| \(\beta\gamma\) | 乘数 | 业务含义 |
|:-------------:|:----:|----------|
| 0.2 | 1.25× | 补贴杠杆很弱，大部分效果就是直接降价 |
| 0.5 | 2.0× | 补贴 1 元的效果等于正常市场的 2 元 |
| 0.8 | 5.0× | 战略亏损区——网络效应显著放大补贴 |

\(\beta\gamma\) 必须小于 1，否则模型分母为负，系统进入正反馈失控（赢家通吃）。

### 5. 免费出行（\(p_u \leq 0\)）在什么条件下成立？

免费出行需要平台用商家收入来补贴用户。在简化场景（\(p_f = 0\)，仅入驻费）下，最优用户价格为：

\[
p_u^* = \frac{A + \beta B + \alpha c - (\beta + \gamma\alpha) \cdot p_l}{2\alpha}
\]

免费出行的条件是 \(p_u^* \leq 0\)，即：

\[
p_l \geq \frac{A + \beta B + \alpha c}{\beta + \gamma\alpha}
\]

也就是说，入驻费 \(p_l\) 必须足够高，平台才能用商家收入覆盖补贴成本。这与直觉相反的关键洞见是：**免费出行不取决于网络效应有多强（\(\beta\gamma\) 多大），而取决于入驻费有多高。** 网络效应（\(\beta, \gamma\)）影响的是达到免费出行的难度——\(\beta, \gamma\) 越大，临界 \(p_l\) 越低，免费越容易实现。

> ⚠️ **模型边界**：以上结论来自 \(p_l\) 外生给定的简化场景。当 \(p_l\) 内生化时，需要检验联合优化的二阶条件：
>
> \[
> \frac{\partial^2\pi}{\partial p_u^2} < 0,\quad
> \frac{\partial^2\pi}{\partial p_l^2} < 0,\quad
> \det(H) = \frac{4\alpha - (\beta + \gamma\alpha)^2}{D^2} > 0
> \]
>
> Hessian 行列式正性给出：\((\beta + \gamma\alpha)^2 < 4\alpha\)。这是"平台同时拥有两种定价工具时，内点解存在"的数学前提，不属于外生 `pl` 模型的结论范畴。
